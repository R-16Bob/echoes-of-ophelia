# 残响 · 氛围与文风

> 这份文档定的是**怎么写**。角色在 `Design/残响-角色与关系.md`，故事骨架在 `Design/残响-序章：梦境.md`。
>
> 状态：第一版。第 9 节是验收标准，写任何新文本之前先读它，写完对照它。

## 1. 美学公式

```
曾经美丽 → 现在残破 → 残留的思念 → 玩家去了解 → 送走
```

五步缺一不可，缺了就是普通的恐怖游戏。

- **没有「曾经美丽」**，残破只是脏，玩家不会心疼。
- **没有「送走」**，了解就变成了看戏，玩家没有参与感。
- **美不在描写里，在对比里**。你不需要写"这里曾经很美"，你只需要写"值日表还贴在墙上，第三个名字被水泡烂了"。玩家自己会心疼。

所以判断一段文本好不好，只问一句：**它让玩家看见了过去，还是只让玩家看见了现在？**

**恐怖的位置**：恐怖是"美被扭曲之后的样子"，不是独立的调味料。

- 好：一张干净的课桌上放着一双鞋，鞋尖朝外，摆得很正。
- 坏：教室里飘着阴气，让人后背发凉。

恐怖来自**事实本身的错位**，不来自形容词。

## 2. 三条硬规则

写任何一段游戏文本都要过这三条。

### 规则一：一句一个信息点

不要在一句话里塞两个意思。不要用复合比喻（"像 A，又像 B，仿佛 C"）。

### 规则二：最多一个比喻，必须是日常物

比喻的作用是让人**更容易懂**，不是让人觉得你文笔好。所以只能用玩家生活里见过的东西：钥匙、雨、被子、牙、作业本。

### 规则三：游戏文本不是小说

- 一个事件卡的正文：**2–4 句，总共不超过 60 字**。
- 一段旁白：**不超过 4 句**。
- 一句战斗文本：**不超过 25 字**。
- 一段对话：每句不超过 20 字。
- 长句要拆。朗读一遍，卡住就拆。

### 三拍子

从你选中的那段里，规律是三个动作：

```
看见什么 → 剩下什么 → 停在哪
```

以值日表那段为例：

| 拍 | 内容 |
| --- | --- |
| 看见什么 | 值日表还贴在墙上，六月的 |
| 剩下什么 | 第三个名字被水泡烂了，只剩一个「奥」字 |
| 停在哪 | 花坛的杂草长到腰高，越过铁栅去够太阳 |

最后那一句不解释、不总结、不抒情，只是把镜头停在那儿。**这是全篇最重要的技巧。**

## 3. 正反例

### 反例（被毙掉的）

> 月光从破掉的窗格里斜切进来，落地时已经散了，像有人把一整匹白绢铺在走廊上。灰尘在光里悬着，慢慢转，慢到你数得很清楚。尽头有脚步声。很轻，像怕吵醒谁。

**问题**：
1. 两个比喻叠在一起（白绢、怕吵醒谁），且都不是日常物。
2. 信息量是零——读完不知道这是哪、谁在这、要干什么。
3. "慢到你数得很清楚"在替读者下判断，读者没在数。
4. 语气是诗的，不是游戏的。玩家要往前走，这段拖住了他。

**注意**：不是说月光和灰尘不能用。是**不能用它们当主句**。

### 正例（目标文风）

> 值日表还贴在墙上，六月的，第三个名字被水泡烂了，只剩一个「奥」字。花坛的杂草长到腰高，越过铁栅去够太阳。很久以前有人在这里栽过一排向日葵——现在枯秆还立着，像一排安静的人。

**为什么成立**：全段只有一个比喻（安静的人），是日常物，而且它承载了"过去/现在"的对比。信息全是具体的：六月、第三个名字、腰高、一排。读完你知道这里有一个人姓奥。

### 改写示范（现有文本 → 新文风）

**原**（`src/data/story.js` 的"走失"结局整段）：
> 爱丽丝停了下来。她忘了自己要去哪里，也忘了自己为什么会站在这里。走廊很长，两边的门都一样，每一扇门后面都有很轻的呼吸声。她数了数门。数到第七扇的时候，她笑了起来，然后一直没有停下来。

**改**：
> 走廊两边的门一模一样。她数了一遍，七扇。第七扇门后面有人在呼吸，很轻，和她的呼吸一样快。她停在门口，想不起来自己在找谁。

改掉了什么：
- 删掉"她笑了起来，然后一直没有停下来"——这是在用行为替恐怖干活，读者只会觉得莫名其妙。
- 把"每一扇门后面都有很轻的呼吸声"收成"第七扇门后面"——**具体比全面可怕**。
- 结尾落在"想不起来自己在找谁"，回扣 §0 那句话。

**原**（`src/data/story.js` 的序章第一页）：
> 三天前，奥菲莉亚没有回家。警察来过一次，翻了翻她的房间，说这个年纪的女孩离家出走很常见。「过两天自己就回来了。」他们这样说，然后在登记表上画了一个勾。

**改**（新序章不再需要"报案"这套，但句式可以留）：
> 那天晚上之后，奥菲莉亚没有回宿舍。老师问过一次，爱丽丝说她们吵架了。登记表上写的是"外出未归"。

改掉了什么：
- 警察、离家出走、登记表打勾——这些是**成年人的世界**，和封闭女校的质感不搭。
- 换成宿舍、老师、"吵架了"——一句谎话，比一段控诉有用。

## 4. 用词白名单 / 黑名单

### 黑名单（出现即改）

| 类别 | 词 | 为什么 |
| --- | --- | --- |
| 氛围形容 | 诡异、阴森、毛骨悚然、不寒而栗、令人不安 | 替读者下结论。删掉，写事实。 |
| 空转形容 | 莫名、说不出的、难以言喻、莫名地 | 没信息。 |
| 诗化连词 | 仿佛、宛如、好似（连用） | 一个比喻都嫌多，三个就是散文。 |
| 套话 | 空气凝固、时间静止、心跳漏了一拍 | 游戏里用烂了。 |
| 情绪直陈 | 她很害怕、她非常痛苦、她感到绝望 | 用行为写。 |
| 过度修饰 | 幽幽的、惨白的、森然的、死寂的 | 一个形容词能说完的不要两个。 |

### 白名单（优先使用）

- **实物名词**：手、门、窗、水、灰、影、鞋、杯、线、名字、声音、温度、味道、日期。
- **具体动词**：漏、泡、锈、垂、停、数、掉、粘、裂。
- **可数的量**：七扇、六月、第三格、两年前、少一只、剩半瓶。
- **日常比喻**：像被子、像雨、像钥匙、像牙、像作业本。

**一个不用写的检查**：一段文本里如果没有任何一个**能数出来的东西**，它大概是在空转。

## 5. 四类文本的语气差

同一款游戏，说话的位置不同，语气必须不同。混了就会散。

| 类型 | 位置 | 人称 | 句长 | 规则 |
| --- | --- | --- | --- | --- |
| **旁白** | 事件卡、区域描述、结局 | 第二人称"你"，偶尔第三人称"她" | 中 | 客观、克制。不猜玩家心情。最多一个比喻。 |
| **对话** | 角色说话 | 第一人称 | 短 | 各按角色说话方式（见角色文档 §3.4）。**对话里允许不好好说话**——那是人物。 |
| **战斗** | 技能描述、命中/伤害文本 | 第二人称 | 极短 | 动词开头。不抒情。不写"你痛苦地"。"命中"就写"命中"。 |
| **物品** | 装备、消耗品描述 | 第三人称/无主语 | 短 | 写东西本身，不写情绪。**风味文本 ≤ 30 字**。 |
| **系统提示** | 数值、卡牌、提示 | 第三人称 | 极短 | 平。不用"你"。数值文本不要有文学性。 |

**旁白和对话的切换**：旁白用"你"，对话用"我"。同一个事件卡里出现两次切换就要检查——玩家会晕。

## 6. SAN / 思念的文本位置

数值系统保留，但**文本必须重写**。这一节定的是：当数值跳动时，屏幕上出现什么字。

### 名词

| 系统 | 旧称谓 | 新称谓 | 含义 |
| --- | --- | --- | --- |
| 计量条 | 侵蚀 x/5 | **思念** | 你在这里感受到的、还没消化的东西 |
| 抽到的卡 | 疯狂 / 美德 | **残响** | 一段过去住进了你心里 |

**为什么叫思念**：它同时是"想念一个人"和"心里想着"。爱丽丝在这座学校里想奥菲莉亚，所以思念在涨——这不是惩罚，是**她越来越放不下**。

**为什么叫残响**：标题就是这个词。声音停了之后还留在空间里的那一点。学生们的残响、奥菲莉亚的残响、爱丽丝自己的残响。

### 文本模板

**思念上涨**（失去 SAN 时）：
- 不写："你的理智受到了冲击。"
- 写："你想起来了，又不完全想得起来。" / "这里有东西你认得。"

**思念满，抽一张残响**：
- 不写："你陷入了疯狂！"
- 写："你听见了不属于现在的声音。"（固定句，全篇统一，让玩家形成条件反射）

**残响卡本身**：每张卡都有两行——
- 一行是**馈赠**（她想起了什么，因此得到什么）
- 一行是**代价**（她想起了什么，因此失去了什么）

例：

> **残留 · 那只坐垫**
> 馈赠：检定 +1。她记得那间屋子里有人替她挡过风。
> 代价：每场战斗开始时 SAN −1。她记得自己是从那里跑掉的。

写卡的规矩：**两行都必须是"她想起了什么"，不能是抽象的 buff 说明。** 数值写在冒号后面，不在前面。

### 机制变更记录（需在系统 GDD 里落实，本文档不设计系统）

从这一版起，卡牌系统有一处变更：

| 项 | 旧 | 新 |
| --- | --- | --- |
| 卡池 | 疯狂（80%）+ 美德（20%） | **单一卡池：残响** |
| 每张卡 | 疯狂 = 常驻增益+代价；美德 = 一次性 | **每张同时带馈赠和代价**，不再区分好坏 |
| 玩家体验 | 抽卡是赌运气 | 抽卡是**接受一段过去** |

**待定（需要拍板后才能改代码）**：
1. 残响是常驻还是可以消耗掉？
2. 残响之间是否互相作用（同类累积）？
3. 「心理咨询」（旧系统里花钱移掉一张疯狂）在新设定里变成什么？建议改成"整理"——不是移掉，是**把一段记忆放回去**，代价更高。
4. 图鉴分类从"疯狂/美德"改成"残响"，旧存档数据（`alice.codex.v1`）需要迁移。

## 7. 感官配方：每个地方该给玩家什么

每个区域定六件事：光、声、味、温度、干湿、蝶。写事件卡之前先看这张表，避免每张卡都写"阴暗潮湿"。

### 校门 · 前庭

| | |
| --- | --- |
| 光 | 傍晚，最后一层金色。影子很长，人被拉得比实际高。 |
| 声 | 风里有铁链的声音，一下一下，不连续。 |
| 味 | 草、土、铁锈。 |
| 温度 | 暖，但风一起就凉。 |
| 干湿 | 干。石阶缝里有枯草。 |
| 蝶 | **一只**白蝶，跟着走。玩家以为这是气氛。 |

### 教学楼 · 一层走廊

| | |
| --- | --- |
| 光 | 只有尽头一扇窗。中间那段是黑的，但能看见轮廓。 |
| 声 | 自己的鞋跟。走两步停一下，会以为后面还有一个人。 |
| 味 | 粉笔灰、旧木头、一点点霉。 |
| 温度 | 凉，越往里越凉。 |
| 干湿 | 干到发脆。墙皮一碰就掉。 |
| 蝶 | 无。这一段要空。 |

**写法要点**：走廊不写"阴森"。写"两边的门一模一样"和"第几扇"。具体比气氛有效。

### 保健室

| | |
| --- | --- |
| 光 | 窗帘半拉，光是一条一条的。 |
| 声 | 外面有风。屋里很静，静到能听见自己的呼吸节奏。 |
| 味 | 消毒水，很淡了，混着旧布的味道。 |
| 温度 | 比走廊暖。唯一暖的地方。 |
| 干湿 | 干，除了洗手台那一小片。 |
| 蝶 | **一只**，落在积灰的坐垫上。 |

**这是全篇最重要的一个区域**：它是爱丽丝和奥菲莉亚关系开始的地方，也是本 DEMO 的第一次安全屋。暖、安全、有回忆。玩家在这里放松，才能在后半段被推翻。

### 戏剧社后台

| | |
| --- | --- |
| 光 | 顶上一盏，闪，但一直没灭。 |
| 声 | 幕布被风推着蹭地板。 |
| 味 | 樟脑、灰尘、布料。 |
| 温度 | 温的，闷。 |
| 干湿 | 干。 |
| 蝶 | 无。这一段只用声音。 |

**写法要点**：后台是"没演成的那场戏"。所有细节都指向"差一点点"：戏服挂好、台词本翻到一半、名字写在箱子侧面。

### 音乐教室

| | |
| --- | --- |
| 光 | 月光，从高窗进来，落在地板中间。 |
| 声 | 钢琴的一个键偶尔自己响一下（不用解释）。 |
| 味 | 木头、漆、旧谱子。 |
| 温度 | 冷。 |
| 干湿 | **干的**——这一区的湿要留到后面才出现。 |
| 蝶 | 无。 |

### 宿舍 · 梦的最后一格

| | |
| --- | --- |
| 光 | 没有光。 |
| 声 | 呼吸。只有呼吸。 |
| 味 | 无。 |
| 温度 | 冷到皮肤发紧。 |
| 干湿 | **潮**。只有这里。 |
| 蝶 | **一只**，在窗台上，不飞。 |

**写法要点**：这是揭穿的地方，所以全部规矩都反转——前面用具体事实，这里只用感觉；前面最多一个比喻，这里可以不用比喻。反差本身是武器。

## 8. 水与蝶的写法

（设定见角色文档 §7，这里只定怎么用）

### 水

- **序章前 70% 不出现任何水**。连"潮湿"都不写。这是纪律。
- 第一次出现必须**偏离画面中心**，且不给特写：走廊尽头"地上有一小片湿"。
- 第二次（保健室洗手台）必须**被对话打断**，让玩家看见但不允许停留。
- 第三次（幻影脚下）必须是**反光**，不是水本身。
- 最后一次（缎带是湿的）必须**一句话说完，不解释**。

### 蝶

- 蝶**不参与玩法**。它不是提示，不能指向下一步。玩家如果盯着蝶找路，会找不到。
- 蝶出现时，文本只用一句话，且不解释："有一只蝶，白的。"
- 蝶变黑**只在 SAN 低于一半时**生效，且不加任何文字说明——玩家自己会发现。

## 9. 验收标准

写完之后自己过一遍，全部可数、可判。

### 单卡验收（每张事件卡 / 每段旁白）

- [ ] 全文没有一个黑名单词。
- [ ] 比喻数量 ≤ 1。
- [ ] 至少有一个**可数的具体事实**（数字、日期、名字、物件、量词）。
- [ ] 正文 ≤ 60 字 / 旁白 ≤ 4 句。
- [ ] 最长的一句 ≤ 40 字，朗读不卡。
- [ ] 结尾停在具体的东西上，不总结、不抒情。
- [ ] 通过"看见过去"测试：读完能说出**这里曾经有谁、发生过什么**。

### 单场战斗验收

- [ ] 战斗前能被回答：这个敌人是谁、他在乎什么。
- [ ] 战斗后能被回答：玩家送走了什么。
- [ ] 战斗文本 ≤ 25 字，动词开头。
- [ ] 战斗文本里没有一句抒情。

### 单个角色出场验收

- [ ] 台词符合该角色的句长与口头习惯（对照角色文档 §3.4 / §4.3）。
- [ ] 该角色至少说了一句**只有她会说的话**。
- [ ] 该角色没有说禁忌清单里的话。

### 整体验收（序章通关后）

- [ ] 玩家能说出奥菲莉亚是谁（性格，不只是名字）。
- [ ] 玩家能说出爱丽丝丢下了她。
- [ ] 玩家能察觉"整段是梦"是被设计的，不是被解释的。
- [ ] 玩家对水有印象，但说不出为什么。
- [ ] 玩家想继续玩。

**最后一条是唯一的真验收。** 前面几条是为了让最后一条有可能成立。
