## 0. 一句话

**爱丽丝要找的不是失踪的人，是她丢下的人。**

这句话是全篇的轴。所有文本、所有战斗、所有道具描述，最终都要能回到这句话上。

---

## 1. 叙事骨架：三层时间

序章 DEMO 的舞台是**梦**，但不是一开始就告诉玩家。

| 层 | 内容 | 玩家的认知 |
| --- | --- | --- |
| **真实** | 那个周末，两人溜进废校探险。夜里出事，奥菲莉亚在前面挡着，爱丽丝因为害怕跑了。她不知道自己怎么回的宿舍，手里只剩一条缎带。奥菲莉亚从此失踪。 | 不知道 |
| **梦** | 那一夜的重演。梦里的奥菲莉亚还在，还会笑，会牵她的手。前半程轻松、安全、有说有笑；直到幻影出现，把"她还在"这件事拆穿。 | 以为是现在 |
| **醒来** | 必败战结束。爱丽丝惊醒，缎带还在手里。她决定去找。 | 知道是梦，序章结束 |

**为什么这样排**：玩家前半程的轻松，必须在结尾被一次性推翻。安全感不是浪费，是伏笔。

**写法上的硬约束**：
- 梦里的奥菲莉亚**不能有破绽**。不要提前给她加"不太对劲"的细节，不要让她说话有回音、不要让她影子不对。她的虚假要靠**结尾**揭穿，不靠前半程暗示。
- 唯一的伏笔是**水**。梦里有不该有的湿（见 §7 和文风文档），但玩家第一次不会注意。
- 幻影出现的那一刻，奥菲莉亚的台词要短、要平。不咆哮，不控诉。她说的是爱丽丝自己心里的话。

## 2. 世界设定摘要

只写角色需要知道的部分，完整世界观留到正篇。

- **圣艾格尼丝学园**：山里的封闭教会女校，初高中一贯制。三年前开始出事，两年前正式废校。
- **出事的方式**：以社团、小团体、朋友为单位。一组人一起失踪，或者一起死。外人看是事故，校方和教区压了下来。
- **为什么按团体发生**：因为那所学校里，人只有两种活法——属于一个团体，或者谁都不属于。爱丽丝是后者。这是全篇最重要的设定，敌人的形状由此而来（见 §6）。
- **现在**：两人就读山下的寄宿制女校。从宿舍走到废校大约四十分钟，周末没人管。
- **记忆空白**：两人对废校那两个学期的记忆有大片缺口。不是失忆，是**记得形状、填不上内容**——知道走廊有多长，不知道走廊上发生过什么。这一点她们都察觉到了，但谁都不提。

### 时间线

| 时间 | 爱丽丝 | 奥菲莉亚 | 发生了什么 |
| --- | --- | --- | --- |
| 三年前 · 秋 | 13 · 初一 | 14 · 初二 | 转入学园。第一批人失踪。保健室那只猫开始等不到人。 |
| 三年前 · 冬 | 13 | 14 | 戏剧社的公演取消。道具封在后台。 |
| 两年前 · 春 | 14 · 初二 | 15 · 初三 | 最严重的一次。废校决定下达。 |
| 两年前 · 夏 | 14 | 15 | 一起转入山下女校，读初三。记忆开始出缺口。 |
| 一年前 · 春 | 15 | 16 | 一起升入该校高中部。 |
| 今年 · 秋 | 16 · 高一 | 17 · 高二 | 奥菲莉亚提议回去看看。**那一夜**。 |

**注意**：爱丽丝在那所学校只待了不到两年，可她的记忆里有一段是空的。她 16 岁，空掉的两年占了人生的八分之一。这个比例要让人感觉到。

## 3. 爱丽丝

### 基本信息

| | |
| --- | --- |
| 年龄 / 年级 | 16 · 高一 |
| 身份 | 转学生（第二次转学）。在现在的学校，仍然谁都不熟。 |
| 外貌 | 齐肩短发，发尾有点翘，她自己懒得管。蓝色水手服，白色小腿袜，玛丽珍鞋。 |
| 体态 | 走路靠边走，不占中间。坐着的时候手放在膝盖上。 |
| 眼神 | 看人的时候不太看眼睛，看对方的下巴或者肩膀。 |
| 常用物件 | 保温杯（正篇的初始武器，也是她的习惯——手总要拿着点什么） |

### 性格：外冷内热的三个具体表现

不要写"她其实很温柔"这种定性，要能演出来。

1. **她的话比心里的话少一半**。想说的很多，出口的只剩一句。所以她的话经常短得不礼貌。
2. **她先做，再解释**。有人需要帮忙的时候，她不会先问"要不要帮忙"，手已经伸出去了，然后才小声说一句"我帮你拿"。
3. **她的冷淡是有方向的**。对陌生人冷，对奥菲莉亚不冷——但也不热，是那种"你说什么我都听着"的安静。

胆怯是她的底色，不是她的性格缺陷：
- 她怕黑，怕一个人，怕所有会发出声音的旧东西（沿用现有设定，很好用）。
- 她怕的是**过程**，不是**结果**。让她"走进黑走廊"她腿软，但你告诉她"走过去就能见到奥菲莉亚"，她会走。
- 所以她的勇气永远需要一个具体的对象，不能是抽象的"勇敢"。

### 她怎么说话

| 项 | 写法 |
| --- | --- |
| 句长 | 短。常在三到七字之间。 |
| 句式 | 陈述为主。很少用疑问句；要问的时候会先停一下，然后问得很直接。 |
| 口头习惯 | 句尾常挂在半空："……嗯。" "……大概。" "……我知道。" |
| 紧张时 | 语序会乱，说半句就停，改口。 |
| 生气时 | 不说话。 |
| 撒谎时 | 会补充细节。她平时话太少，一多说就是编的。 |
| **不会说** | 不会说"我害怕"（她会说"我们走吧"）。不会说"我错了"（她会说"对不起"，然后沉默）。不会主动叫人名字——除了"奥菲姐姐"，那是她唯一叫得出口的称呼。 |

**示范**（可用于事件对话）：

> 奥菲莉亚：「怕吗？」
> 爱丽丝：「……不怕。」
> 奥菲莉亚：「你手在抖。」
> 爱丽丝：「……那是因为冷。」

### 她要什么 / 怕什么 / 不知道什么

- **要**：奥菲莉亚在身边。具体到"她坐在我旁边的位置上"这种程度。
- **怕**：再一次一个人。不是死，是一个人。
- **不知道**：那一夜她跑掉的时候，奥菲莉亚有没有叫她。她记不清了。她也不敢确定。**这是全篇的核心悬念，不要在序章里回答。**

## 4. 奥菲莉亚

### 基本信息

| | |
| --- | --- |
| 年龄 / 年级 | 17 · 高二，比爱丽丝高一级 |
| 身份 | 学园时期就是学姐。是那种"所有人都认识她"的人。 |
| 外貌 | 长发，扎起来的时候用缎带。缎带是**蓝的**（初版可以是蓝的；如果美术希望更醒目，换红的，但必须一以贯之）。 |
| 体态 | 走路带声音，坐下就靠，占地方。 |
| 眼神 | 看人的时候会看眼睛，看得很稳。 |
| 常用物件 | 缎带（序章的锚点物件）、随身的小本子 |

### 性格：温柔与坚强

- **她的温柔是主动的、有重量的**。她会替你做决定，而且做得对——所以你会依赖她。这正是问题所在。
- **她的坚强不是不哭**。她哭，只是哭完会接着做该做的事。她不说"没事的"，她说"我来想办法"。
- **她很受欢迎，但这件事她自己不觉得重要**。别人找她，她应付得轻松；爱丽丝找她，她会推掉别的事。这个差别要在文本里可感，但不要明说。

### 她怎么说话

| 项 | 写法 |
| --- | --- |
| 句长 | 中长句，语气轻快，爱开玩笑。 |
| 句式 | 祈使句多。"过来。" "别看了。" "抓着我的手。" |
| 口头习惯 | 爱给东西起外号、爱用反问句逗人。会管爱丽丝叫"小爱丽丝"。 |
| 紧张时 | 变短。玩笑会突然停掉——这是玩家能察觉她不对劲的唯一破绽。 |
| 生气时 | 安静地说一句最重的话，然后继续做。 |
| **不会说** | 不会说"都听你的"（她习惯替人做决定）。不会说"我很怕"（她会说"我有点冷"）。**不会承认自己也在害怕**，直到最后一刻。 |

**示范**：

> 奥菲莉亚：「这走廊你有印象吗？」
> 爱丽丝：「……有点。」
> 奥菲莉亚：「我一点都没有。」她把缎带从头绳上解下来，缠在手腕上，"那正好，你带路我跟着，今天换你罩我。"

### "奥菲姐姐"的边界

这条关系不能只有甜，否则她失踪的份量不够。

- **正常区**：她替爱丽丝做决定，爱丽丝接受。两个人都舒服。
- **临界区**：她开始替爱丽丝决定"她该不该去想那些事"。这时候爱丽丝不说话了。**序章不点破这一层，正篇点破。**
- **越过线**：她为了爱丽丝去承担不属于她的危险，而且不告诉爱丽丝。**序章她做了这件事——就是挡在前面那一晚。**

一句话：**她的温柔是保护，她的保护是越界，她的越界让她出事。** 这是这个角色唯一需要的设计逻辑。

## 5. 关系：四个阶段

写给文案和关卡，每一阶段定一种语气。

### A. 初识 · 学园期（三年前）

- 爱丽丝是转学生，谁都不属于。奥菲莉亚是那个主动坐到她旁边的人。
- 关键场景：**保健室**。爱丽丝被同学排挤到不敢回教室，课余在保健室待着。奥菲莉亚装着来量体温，来了一个学期。
- 保健室那只猫是这段关系的见证（见 §7）。

**语气**：温和、带点笨拙。全篇最暖的一段。

### B. 支撑 · 转学期（两年前 — 现在）

- 两人一起转入山下女校。爱丽丝变得沉默、做噩梦、不能适应。奥菲莉亚一直在。
- 这一段是**消耗关系**：奥菲莉亚在撑，爱丽丝在依赖。两个人都没说出来。
- 关键场景：宿舍夜谈。爱丽丝半夜做噩梦坐起来，奥菲莉亚的床在隔壁，她不过来，只是隔着床帘说"我在"。

**语气**：安静、有点累。甜度降下来，但更亲。

### C. 探险 · 那一夜

- 奥菲莉亚提议回去看看，理由是"说不定能想起点什么，你能好起来"。
  **她没说的理由**：她自己的记忆也开始漏了，她怕。
- 这一段要**好玩**。两个人在废校里打闹、抢手电、说废话、互相吓。玩家在这里感到安全。
- 这是全篇唯一一次两人都开心的段落。要写足。

**语气**：轻、吵、有笑。

### D. 逃走与失踪 · 梦的结局

- 出事。奥菲莉亚在前面挡着。爱丽丝跑了。
- 这一段不写打斗，写**距离**：她跑的时候听见了什么／没听见什么；她回头了吗；手上为什么只剩缎带。
- 然后：**她不知道怎么回的宿舍。**

**语气**：短句、失序、不解释。

### 附：梦里的关系

梦里的奥菲莉亚是**爱丽丝希望的那个版本**——更温柔一点，更以她为中心一点，不会累一点。

写法上有两个可用的差别：

1. 梦里奥菲莉亚从不抱怨累，也不提自己的记忆。
2. 梦里奥菲莉亚永远知道下一步往哪走。

这两条在结尾会变成刀：幻影出现时，先说"我从来不知道往哪走"。

## 6. 过去：以社团为单位

### 结构

废校的惨剧按团体发生，所以敌人也是按团体。三类：

| 线 | 单位 | 敌人的形状 | 玩家能做什么 |
| --- | --- | --- | --- |
| **学生线** | 社团、小团体、朋友组 | 一组人变成一个东西。面目模糊，但制服、道具、声音还留着。 | 了解、送走 |
| **教职员线** | 个人 | 门房、舍监、保健老师。孤独的，没有团体，所以更难送走。 | 对抗为主 |
| **奥菲莉亚线** | 一个人 | 幻影。不属于以上任何一类。 | 只能输 |

**为什么教职员线打得多、学生线懂得多**：团体消散时留下的是感情（一群人彼此在意过），个人消散时留下的是执念（一个人守着一个位置）。前者能听，后者只能挡。

### 名单骨架

序章只需要三个，其余是正篇候选。**所有条目都必须能回答四个问题**：他们是谁 / 他们在乎什么 / 他们留下了什么 / 怎么送走。

| 敌 | 属于谁 | 他们是谁 | 留下了什么 | 怎么送走 | DEMO |
| --- | --- | --- | --- | --- | --- |
| 懒散的黑猫 | 保健室（学生线，意外的成员） | 保健老师养的猫。老师走了，猫每天还在同一个窗台等。 | 窗台上的一圈毛、被压扁的坐垫 | 抚摸。代替那个不会回来的人安抚它 | ✔ 教程·特殊行动 |
| 人偶 | 戏剧社（学生线） | 三年级最后一次公演，取消了。道具封在后台两年。 | 戏服、剧本上划掉的台词、别人的名字 | 打碎。它们已经站了两年的姿势，该放下了 | ✔ 教程·武器与装备 |
| 奥菲莉亚的幻影 | —— | 爱丽丝记忆里的奥菲莉亚 | 缎带 | 打不赢。这一场本来就是输 | ✔ BOSS·必败 |
| 无面的合唱团 | 音乐社（学生线） | 校歌比赛拿了第一的那一届。所有人的脸都是同一个。 | 奖状、谱子上画满的同一个圈 | 奥术/指挥棒 | 正篇 |
| 干涸泳池里的东西 | 游泳社（学生线） | 夏天，训练，水停了。 | 池底的一只拖鞋、更衣室的名牌 | 水（她怕水，但水是她的） | 正篇 |
| 门房留下的东西 | 教职员线 | 门房，最后一个离开的人。他锁了所有人，然后没走成。 | 一串钥匙、登记本上最后一行日期 | 对抗 | 正篇 |
| 舍监的影子 | 教职员线 | 舍监，夜里查房。她查到了不该查的东西。 | 手电、点名册 | 对抗 | 正篇 |

> 泳池那条是对"水=沉下去"的正面回收。放进正篇，别在序章用。

### 敌人设计规则（写给以后所有人）

每个敌人必须有三样东西，缺一样就不要做：

1. **一件遗物**：能拿在玩家手里、能看、能带走的实物。
2. **一句遗言**：不是台词，是留在遗物或墙上的字，通常不完整。
3. **一个送走的方式**：可以是打碎，可以是抚摸，可以是把东西放回原处。**送走不等于打赢。**

这条规则的用处：它保证玩家在战斗里知道自己在做什么，而不只是在扣血条。

## 7. 水与蝶

### 水：她的主题不是水，是「沉下去」

- 整个序章是**干的**。干到玩家不会想到水。
- 用到水的地方只有四处，全在梦的后半段：
  1. 走廊尽头天花板在漏，地上有一小片湿。位置偏离正中。
  2. 保健室的洗手台，水一直开着，很小。
  3. 幻影出现时，脚下有水的反光。**她没有踩出声音。**
  4. 缎带是湿的。这一条在梦的最后一刻才被写出来。
- 所以水不是她的符号，是**证据**。玩家第一次看到湿的时候不会在意，进入后半段才明白。

### 蝶：谁在这里思念过

- 蝶 = 残留的思念的可见形态。不是提示图标，是"这里有人在意过"。
- 蝶**不解释**。全篇没有任何一句台词说明蝶是什么。
- 序章只出现三次：
  1. 前庭，跟着爱丽丝飞过铁门。玩家以为是气氛。
  2. 保健室窗台，一只落在积灰的坐垫上。就在猫待过的地方。
  3. 结尾醒来前，梦的最后一格。这一只不飞。
- **SAN 低时蝶变黑**（或变成纸叠的）。这是玩家能读到的唯一压力指示，不需要 UI 说明。

## 8. 禁忌清单

不写进游戏，但写文档的人必须知道。

### 爱丽丝不会做的

- 不会主动提废校。
- 不会主动问奥菲莉亚"你记得吗"。
- 不会在别人面前哭。她会背过去，肩膀不动。
- 不会求助。她宁可站着不动。

### 奥菲莉亚不会做的

- 不会在爱丽丝面前喊累。
- 不会说"我需要你"。她需要，但她不说。
- 不会为了让爱丽丝安心而撒谎说"我记得"——她会把话题挪开。
- 不会替爱丽丝道歉（替她挡事可以，替她认错不行，这是她唯一的分寸）。

### 两个人共同不会做的

- **不会提"如果那天"**。序章里一次都不出现。正篇里出现一次，就够了。
