# 残响学园 · Echoes of Ophelia

> 爱丽丝与失踪的奥菲莉亚 —— 一款以文字描述为主的类跑团 · 肉鸽 · 生存恐怖 DEMO。

废弃的圣艾格尼丝学园。夜里三点十七分，铁门自己开了一条缝。爱丽丝循着好友最后留下的信息走进来，要在这个闹鬼的校园里找到奥菲莉亚，然后带她出去。

**DEMO 内容**：序章 → 校门·前庭 → 教学楼·一层走廊 → 音乐教室 → 幕布后面（结局）。约 30–45 分钟一周目。

---

## 运行

需要 Node.js 18+（不需要安装任何依赖）。

```powershell
# 方式一：双击 start-game.bat

# 方式二：命令行
node server.mjs          # 打开 http://127.0.0.1:4173
node server.mjs --open   # 启动并自动开浏览器
node server.mjs --port 5000
```

> 为什么需要服务器：项目使用原生 ES Module，`file://` 协议下浏览器会拒绝跨文件 import。
> 服务器只做静态文件分发，没有任何后端逻辑。

### 自动试玩 / 冒烟测试

```powershell
npm test              # 先跑规则断言，再跑 6 局自动试玩
npm run verify        # 只跑规则断言（49 项）
npm run sim -- 20     # 指定自动试玩局数
```

用 Node 里的极简 DOM 垫片跑完整流程：点选项、打战斗、进安全屋、升级、抽卡，检查每个界面都能渲染、没有运行时报错，并输出到达结局 / 中途失败 / 卡住的比例。

## 已实现

- **开始菜单 / 序章 / 规则 / 制作说明**，标题、噪点、暗角与渐显的页签式排版。
- **区域探索**：校园分区域，每次探索抽一张事件卡，并按表现增加 5%–10% 探索度（检定成功、少受伤、拿到物品会更多）；50% 与 90% 各进一次安全屋；100% 触发区域 BOSS 与固定剧情，结束后解锁下一区域。
- **事件卡**：文字描述 + 2–3 个选项；选项支持属性检定（1d12 暗骰）、物品 / 装备 / 专长免检定、直接进入战斗。23 张随机事件 + 3 个区域固定剧情（另有 1 张未开放的天台事件）。
- **双资源**：HP / SAN，任意归零进入对应失败结局（力竭 / 走失）。
- **六属性**：STR / DEX / PER / KNW / CHR / LUK，装备与卡牌会修正数值与检定。
- **战斗**：200t 时间轴、排招 / 撤回 / 执行、命中率与属性加成、武器技能组、多段与处决、道具不耗时；所有武器都带通用技能「准备动作」（40t，下一次攻击必定命中）。
- **伤害类型与弱点**：武器分斩击 / 打击 / 穿刺 / 奥术，并绑定一项属性（DEX / STR / KNW 等）；敌人有弱点类型，用对应武器命中时每段 +1 伤害。武器说明与敌人面板上都能悬停查看。
- **事件日志**：右下角「事件日志」或按 L 打开，记录最近 100 条（内存最多 300 条）探索、检定、伤害 / 回复、XP、硬币、道具、商店与战斗结算；可随时收起。
- **成长**：XP 满 100 升级 → 三选一专长 → 再选一项属性 +1（可连升）。
- **疯狂 / 美德**：HUD 显示「侵蚀 x/5」。每累计失去 5 点 SAN 抽一张（80% 疯狂 / 20% 美德）并清零；恢复 SAN 会让侵蚀倒扣。疯狂是常驻代价，美德是一次性缓冲（下一次检定 +1、下一场战斗首次命中 +5% 等），用完即消失。抽卡时有整屏提示。
- **安全屋**：进入时少量恢复 3 HP / 3 SAN；可花 6 硬币「睡一会儿」（+6 HP / +8 SAN）、2 硬币续杯、6 硬币做一次心理咨询移除一张疯狂卡。货架随机 5 件，已拥有的装备 / 关键物品不再出现，买下即下架。
- **物品 / 装备**：消耗品、关键物品、武器 / 服装 / 5 个饰品槽；背包装备栏悬停可看说明与技能组；随时换装，非战斗可用道具。
- **保温杯**：既是消耗品也是武器 —— 喝一口回 2 HP、次数 -1；装备后伤害 = 1 + 剩余次数，喝空后只剩 1 点。
- **线索系统**：检定成功可获得线索并回 2 SAN，收录在「线索」浮层里，作为后续剧情的钩子。
- **设置**：可关闭「显示检定数值」，关闭后只显示成功 / 失败（设置存在 localStorage）。

## v0.5 节奏、压力与信息透明

1. **心理咨询**：不再自动移除，打开列表由玩家自己选一张疯狂卡；每次安全屋只能咨询一次。
2. **随机探索度**：每次探索增加 5%–10%。检定成功、没有掉 HP / SAN、拿到物品或线索都会让增量更高；失败且受伤时接近 5%。安全屋改为按「跨过 50% / 90%」触发，而不是固定步数。
3. **一次性美德**：美德卡不再常驻，改为立刻回复 + 一次性 buff（下一次检定 +1、下一场战斗首次命中 +5%、下一击伤害 +2 等），用掉即消失；疯狂仍是常驻代价。角色卡新增「临时效果」区。
4. **敌人压力**：三名普通敌人 HP 上调（影子 26 / 人偶 24 / 合唱团 64），部分事件失败会直接进入战斗；每个区域末尾固定一场 BOSS（门房留下的东西 / 舍监的影子 / 合唱团），部分检定成功可以绕开。
5. **敌人意图**：战斗面板显示「下一击：HP -3 / SAN -1」与整轮行动序列，敌人每回合的威胁一眼可见。
6. **数值透明**：角色卡新增「加成汇总」（上限、命中、伤害、减伤、检定、治疗、时间、经验、回 SAN、硬币）与来源列表；武器行显示命中拆解 `75 武器 + 10 等级 + 5 装备`、伤害拆解与耗时系数；战斗界面同样显示命中率与普攻伤害的构成。之前出现的 95% 命中就是「武器 75 + 等级 20 + 装备 5 − 敌人 POW 5」这类叠加，现在可以逐项核对。
7. **悬停只显示效果**：专长、疯狂 / 美德卡、商店货品默认显示风味文本，悬停时才展开纯效果（如「击杀敌人时回复 1 SAN」），不再重复描述。
8. **命中成长修正**：等级改为每级 **+1%** 命中（原先误写成每级 +10%），1 级就是 +1%；难度改由敌人 POW 与 HP 调节，不再靠等级白送命中。
9. **通用技能「准备动作」**：任何武器都有，消耗固定 40t，不造成伤害，让**下一次攻击必定命中**。低命中武器可以先垫一刀保底，也可以配合十字斩这类高耗技能。
10. **安全屋触发修复**：此前用「探索度 ≤ 阈值」判断，跨过 50% 后会直接去找 90%，导致安全屋永远不触发。现在用「已跨过且未访问」，跨过 50% / 90% 后的第一个事件结束就进安全屋。
11. **检定成功不再损失 SAN**：成功分支里的负 SAN 一律按 0 处理，界面不会出现「SAN -1」而实际数值不动的情况；失败分支的 SAN 损失照常。

平衡基线（v0.5）：`npm run verify` 54/54；`npm test` 6 局平均 3–4 局到达结局、0 卡死，约 110–126 步（随机策略；人类玩家会更高）。

## 接下来可以做什么

- **天台区域**：数据里已留好 `roof`（需要旧校徽钥匙解锁），补事件卡与固定剧情即可。
- **正式美术**：按上表替换 12 个插画位，加立绘表情差分。
- **音频**：目前没有声音；建议加环境底噪、心跳（低 SAN）、战斗打击音。
- **存档**：`Game.createState()` 已经把状态收在一个可序列化对象里，接 `localStorage` 不难。
- **更多内容**：事件卡 / 敌人 / 专长 / 卡牌都是纯数据表，照着现有结构加即可，规则层无需改动。
- **难度调优**：`src/data/enemies.js` 与 `src/data/skills.js` 的数值，配合 `npm test` 的自动试玩快速验证。

详细公式、数据格式与扩写方法见 [DESIGN.md](DESIGN.md)。
